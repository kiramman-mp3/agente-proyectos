## Convenciones de esta documentación

*   Los comandos de consola están escritos para **Windows (PowerShell)**, salvo que se indique otra cosa.
*   Los valores sensibles nunca aparecen en estos documentos. Donde hace falta uno se usa un marcador como `<MASTER_KEY>`.
*   Las rutas se escriben relativas a la raíz del repositorio.
